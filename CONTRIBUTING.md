# Contributing to ESSA-AI

ESSA-AI is an experimental research project. Contributions are welcome, but the project prioritizes clear hypotheses, reproducible experiments, and architectural reasoning over feature volume.

## Before contributing

Please read:

- `README.md`
- `docs/ESSA_FOUNDATION.md`
- `docs/SYMBOLIC_CORE.md`

## Contribution principles

1. Keep the core architecture dependency-light.
2. Do not assume next-token prediction is the fundamental cognitive primitive.
3. Separate philosophical claims from engineering claims and measurable hypotheses.
4. Prefer small experiments over large speculative implementations.
5. Document assumptions and negative results.
6. Keep self-awareness claims computational and testable; do not claim consciousness without evidence.

## Development

The v0.1 core has no runtime dependencies. Python 3.11+ is recommended.
