The SELF is structured, not implied.

ESSA makes computational self-awareness explicit, testable, and serializable. It is not a claim of consciousness. It is a small working model of identity continuity, substrate awareness, and state transition learning.

Awareness as an executable loop.

ESSA begins with a persistent identity and updates itself through observation. Each action leaves evidence: previous state, observed result, predicted state, next state, and history.

The project stays deliberately small so the claim can be inspected in code instead of hidden inside a black box.
