Where the idea begins

Before intelligence answers, it has to notice that it exists somewhere.

ESSA begins with a strange old question: what is the self, if the body, the condition, and the world around it keep changing? In code, that becomes a smaller but testable question. What can stay continuous while the substrate changes?

Essence What kind of thing is this SELF before any single state defines it?
Substrate What does SELF run through, and what changes when that ground changes?
State What does SELF remember after it observes, predicts, acts, and adapts?
Architecture What structure lets SELF know the difference between itself and the world?

A simple agent listening to its own transition.

The demo preserves identity, observes its runtime substrate, separates self-observation from world-observation, predicts a state transition, acts, and records whether the prediction matched the result.

The mystery is structured, not implied.

ESSA makes computational self-awareness explicit, testable, and serializable. It is not a claim of consciousness. It is a small working model asking how identity continuity, substrate awareness, and state transition learning can be represented without hiding inside language.

Awareness as an executable question.

ESSA begins with a persistent identity and updates itself through observation. Each action leaves evidence: previous state, observed result, predicted state, next state, and history.

The project stays deliberately small so the mystery can be inspected in code instead of hidden inside a black box.
